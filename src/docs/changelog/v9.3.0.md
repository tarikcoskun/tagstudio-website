## Added
- Added playback previews for video files (by @DrRetro2033 in https://github.com/TagStudioDev/TagStudio/pull/149)
- Added Boolean "and/or" search mode selection (by @YoyloNerd in https://github.com/TagStudioDev/TagStudio/pull/232)
- Added ability to scan and fix duplicate entries *(not to be confused with duplicate files)* from the "Fix Unlinked Entries" menu (by @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/204)
- Added “Select All” (<kbd>Ctrl</kbd>+<kbd>A</kbd> / <kbd>⌘ Command</kbd>+<kbd>A</kbd>) hotkey for the library grid view (by @yedpodtrzitko in https://github.com/TagStudioDev/TagStudio/pull/217)
- Added "Clear Selection" hotkey (<kbd>Esc</kbd>) for the library grid view (by @PencilVoid in https://github.com/TagStudioDev/TagStudio/pull/259)
- Added the ability to invert the file extension inclusion list into an exclusion list (by @Thesacraft in https://github.com/TagStudioDev/TagStudio/pull/251)
- Added default landing page when no library is open (by @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/258)

## Fixed
- TagStudio will no longer attempt to or allow you to reopen a library from a missing location (by @Loran425 in https://github.com/TagStudioDev/TagStudio/pull/238 and https://github.com/TagStudioDev/TagStudio/pull/240)
- Fixed `PermissionError` when attempting to access files with a higher permission level upon scanning the library directory (by @Thesacraft in https://github.com/TagStudioDev/TagStudio/pull/228)
- Fixed RAW image previews sometimes not loading (by @Thesacraft in https://github.com/TagStudioDev/TagStudio/pull/228 and @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/233)
- Fixed most non-UTF-8 encoded text files from not being able to be previewed (by @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/233)
- Fixed "Refresh Directories"/"Fix Unlinked Entries" creating duplicate entries (by @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/204)
- Other miscellaneous fixes

## Changed
- Renamed "Subtags" to "Parent Tags" to help better describe their function
- Increased number of tags shown by default in the "Add Tag" modal from 29 to 100
- Documentation is now split into individual linked files (by @Gawidev in https://github.com/TagStudioDev/TagStudio/pull/194) and updated to include future features
- Replaced use of `os.path` with `pathlib` (by @Icosahunter in https://github.com/TagStudioDev/TagStudio/pull/156)
- `.cr2` files are now included in the list of RAW image file types (by @PossiblePanda in https://github.com/TagStudioDev/TagStudio/pull/231)
- Minimum supported macOS version raised to 12.0
