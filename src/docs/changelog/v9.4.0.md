***NOTE:*** [FFmpeg](https://ffmpeg.org/) is required for video thumbnails and playback.
## Added
* Copy and paste fields by @Creepler13 in https://github.com/TagStudioDev/TagStudio/pull/79
* Add multiple fields at once by @yedpodtrzitko in https://github.com/TagStudioDev/TagStudio/pull/134
* Drag and drop files in/out of the program by @Creepler13 in https://github.com/TagStudioDev/TagStudio/pull/153
	* Files can be shared by dragging them from the thumbnail grid to other programs
	* Files can be added to library folder by dragging them into the program
* Manage Python virtual environment in Nix flake by @seakrueger in https://github.com/TagStudioDev/TagStudio/pull/229
* Ability to create tag when adding tags by @bjorn-out in https://github.com/TagStudioDev/TagStudio/pull/262
* Blender preview thumbnail support by @050011-code in https://github.com/TagStudioDev/TagStudio/pull/273
* File deletion/trashing by @PeterBouSaada in https://github.com/TagStudioDev/TagStudio/pull/282 and @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/409
	* Added right-click option on thumbnails and preview panel to delete files
	* Added Edit Menu option for deleting files
	* Added <kbd>Delete</kbd> key shortcut for deleting files
* Font preview thumbnail support by @Thesacraft in https://github.com/TagStudioDev/TagStudio/pull/307
	* Short "Aa" previews for thumbnails
	* Full alphabet preview for the preview pane
* Sort tags by alphabetical/color by @samuellieberman in https://github.com/TagStudioDev/TagStudio/pull/329
* File explorer action follows OS naming by @SupKittyMeow in https://github.com/TagStudioDev/TagStudio/pull/370
* Preview Source Engine files by @FavroiteGamers in https://github.com/TagStudioDev/TagStudio/pull/373
* Expanded thumbnail and preview features by @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/390
	* Add album cover art thumbnails
	* Add audio waveform thumbnails for audio files without embedded cover art
	* Add new default file thumbnails, both for generic and specific file types
	* Change the unlinked file icon to better convey its meaning
	* Add dropdown for different thumbnail sizes
* Show File Creation and Modified dates; Restyle file path label by @CyanVoxel in https://github.com/TagStudioDev/TagStudio/pull/430
